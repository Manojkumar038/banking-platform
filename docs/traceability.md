# Jira and GitHub traceability

Epic: EPIC-100 — Digital Banking Platform.

| Feature | Scope | Story keys |
|---|---|---|
| F1 | Authentication & Security | US101–US105 |
| F2 | Account & Beneficiary Management | US106–US110 |
| F3 | Payments, Transfers & Notifications | US111–US118 |

Use Jira story IDs in branch names, commit subjects and PR descriptions. Examples:

- Branch: `feature/US101-registration`
- Commit: `[US101] Add registration request validation fixture`
- PR: `[US101] Add registration flow scaffold`

Jira issue keys are the primary join key between work items and GitHub artifacts. Feature IDs are the roll-up key for feature-level metrics.
